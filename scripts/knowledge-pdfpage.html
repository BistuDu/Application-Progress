Q: What is a covering index?

A:

When every column the query needs is present in the index, the engine does not need to look up the clustered index again, which removes the extra random IO of a lookup.

Q: Why is a B+ tree preferred for database indexes?

A:

All data lives in the leaf nodes, so internal nodes hold more keys and the tree stays shallow; the leaves are linked, which makes range scans cheap.
