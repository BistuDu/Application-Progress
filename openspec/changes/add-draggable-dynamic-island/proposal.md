# Proposal

## Why

现有扩展需要通过工具栏、右键或快捷键打开功能，网页内缺少随时可用的入口。增加具有 Mac 灵动岛观感的可拖动胶囊，让 JD 采集、题目采集、投递进度和知识库成为网页上的轻量快捷操作，并用平滑形变展示任务状态。

## What Changes

- 在获得浏览器网站访问权限的普通 HTTP／HTTPS 顶层网页默认显示灵动岛，初始位置为右上角；支持按网站关闭，并通过扩展菜单重新开启。
- 收起状态只显示一个简洁图标；采用跟随系统浅深色的半透明磨砂胶囊、细描边与轻阴影，悬停／聚焦显示工具提示，点击原位展开四个功能图标和末尾「更多」。
- 提供识别 JD、识别题目、投递进度、知识库入口；采集使用现有框选与核对流程，管理功能打开现有页面。
- 用户可拖动胶囊，所有网站共用同一持久位置；刷新、切换网站和浏览器重启后沿用，视口变化时自动保持可见。
- 网页采集任务在胶囊中展示识别状态与取消操作，完成或失败短暂反馈后收起；采用无明确百分比的进行中动效。
- 截图前临时隐藏胶囊，确保扩展 UI 不进入截图；异常、取消和核对结束后按网站偏好恢复。
- 保留工具栏、快捷键和右键入口；网页样式、滚动和胶囊之外的点击保持可用，减弱动态效果偏好和键盘操作得到支持。

## Capabilities

### New Capabilities

- `floating-island-ui`: 胶囊视觉与形变、图标收起、快捷菜单、拖动及无障碍交互。
- `floating-island-preferences`: 普通网页自动显示、网站开关、全站共用位置及跨页面持久化。
- `floating-island-capture`: 网页采集入口、截图避让、任务状态／取消及既有识别核对流程兼容。

### Modified Capabilities

无。当前主规格清单为空；已有知识库变更已经实现，这次只接入其入口，不重写项目／题库行为。

## Impact

- 新增 `src/content/island.js` 及独立偏好／几何逻辑；使用原生 Shadow DOM、CSS 和本地矢量图标，不引入前端框架或远程资源。
- 修改 `manifest.json` 的网站权限和顶层 content script 接入；扩展 `src/background.js` 的偏好路由、页面来源校验、截图握手和已有标签页接入。
- `src/content/overlay.js` 增加胶囊协作的状态通知、截图和核对期间避让，并在胶囊不可见时保留原有识别反馈。
- 「更多」提供关闭此网站与位置重置；popup 保留相同控制入口；站点偏好和位置存于独立本地键，岗位记录、API 配置及知识库备份格式保持现有含义。
- 增加几何／偏好／状态逻辑的离线验证、使用正式权限配置的隔离浏览器验证、截图内容检查和多状态视觉验收；更新 README 与分发包。
- 本次范围为轻量入口及网页采集反馈；不在胶囊内重建投递管理或问答编辑，不实现逐站位置、自动截图、所有标签页共享任务进度或系统级桌面悬浮窗。
