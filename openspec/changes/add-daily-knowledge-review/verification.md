## 行为与数据核对

- 当日计划最多 100 题，匹配分类与全部标签，空答案排除；到期薄弱题优先，随机补题不重复，题数不足按实际值。计划创建后设置明日生效，不能通过反复开始换题。
- 首次记住 +1 天，后续 +3／+7／+14／+30，末级保持；需复习重置到次日。日历加天覆盖跨月／年、闰日、DST 和时区，浏览器测试通过只在隔离页面与 worker 内替换 Date 模拟换日，不改变系统时间。
- 自评成功才更新卡片与进度，失败保留可重试界面；container／计划／题目版本校验和串行提交阻止覆盖、旧日期补签及重复增加间隔。
- 临时回想仅留在页面闭包；界面、local、session、备份中分别验证测试哨兵不进入持久数据。关闭／刷新或切题清除，未评分题恢复时重新隐藏答案。揭晓已有答案不调用 AI。
- 跨页更新要求重新揭晓；删除全部待学题不生成零题打卡。历史保留标题和自评，已删除题标注不可用，不复制历史答案。
- 单容器 v2 在首次成功写入时保存；v1 读取纯迁移，不写库。完整 JSON v2 保存学习设置、进度和历史，v1 恢复明确清空学习记录。缺数组／未知版本／坏关系拒绝，恢复预览之后有新评分则冲突；最终检查和写入在同一队列内。即使题目全删仍可导出学习历史。
