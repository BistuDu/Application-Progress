# Proposal

## Why

投递进度页目前把大量首屏高度留给工作台头部、统计卡片和图表，1080p 全屏下表格只能看到约 4 行；地点多行换行进一步把行高撑到约 100px。记录里也没有企业性质字段，用户无法区分央企、国企、私企；表格列固定写死，无法按自己的查看习惯增减字段。结果是每天最常看的投递列表反而成了信息密度最低、最不聚焦的区域。

## What Changes

- 记录新增 `companyType` 字段，取值为央企、国企、私企、其他或空（未标注）；框选核对、手动添加、详情抽屉均可编辑，未知公司保持未标注，不做猜测。
- 新增企业性质自动建议：内置央企/国企/私企公司名词典与关键词规则，识别结果或手动输入公司名时给出建议；JD 截图明确写出企业性质时优先采用截图信息，不覆盖用户已选值。
- 投递表格默认在公司名后显示行内企业性质标签，也可在列设置中打开独立的「企业性质」列（打开后行内标签隐藏，避免重复）；筛选栏增加企业性质筛选；CSV、Markdown 导出增加企业性质列，JSON 备份自动包含。
- 表格列改为完整可配置：表头与筛选栏都提供「列设置」，支持勾选显示列、拖拽排序、按名称搜索、全部显示、恢复默认；可选列覆盖记录时间、地点、薪资、状态、投递日期、来源、下一步、企业性质、岗位类型、学历、经验、人数、截止时间、投递方式、技能、摘要、备注、最后修改、状态变更、来源链接、页面标题和识别模型。新增扩展列默认隐藏，配置写入设置并跨侧栏/全屏共用；侧栏宽度不足时自动隐藏低优先级列。
- 表头列宽可拖拽调整：拖动列右边缘改变宽度，双击恢复默认，键盘方向键微调；列宽写入设置并在刷新、侧栏/全屏切换后保持，侧栏精简模式隐藏调整手柄。
- 把「下一步」从公司单元格里的标签改为可选独立列，降低行高；固定列保留勾选框、公司/岗位和操作。
- 整页重排：工作台标题、标签页、框选工具条压缩为一到两行；投递进度页顶栏压缩；统计卡片与图表收进可折叠「数据概览」，默认只保留一行关键指标并记住展开状态；筛选栏吸顶；表格撑满剩余视口并内部滚动、表头吸顶。
- 地点改为单行截断（如「青岛 等 6 地」）并悬停查看完整内容，行高目标 42–48px，同屏可见行数从约 4 行提升到 15–18 行。
- 视觉保持蓝色主色做精修：统一设计变量、圆角、阴影、字号层级和间距；状态改为「彩色圆点 + 文字」；用内联 SVG 图标替换 emoji；企业性质使用低饱和浅底标签，保证对比度并避免与状态色混淆。
- 保持既有记录、导入导出格式、状态词表、知识库、胶囊和识别流程兼容；旧记录缺少企业性质时按未标注读取，不做迁移写入。

## Capabilities

### New Capabilities

- `job-company-classification`: 企业性质字段、自动建议与手动修正、表格行内标签、筛选和导出行为。
- `job-table-column-configuration`: 表格可选列、完整列目录、拖拽排序、列宽调整与持久化、列设置搜索/全部显示及侧栏精简规则。
- `application-dashboard-layout`: 工作台与投递进度页的紧凑布局、可折叠数据概览、吸顶筛选、全高列表和视觉层级。

### Modified Capabilities

无已发布主规格需要修改。`openspec list --specs` 当前为空，本变更建立上述三个新能力。

## Impact

- 数据与逻辑：`src/lib/store.js` 记录构造与 CSV/Markdown 导出；新增 `src/lib/company-type.js` 承载分类常量、归一化和建议规则；`src/lib/vision.js` 映射截图明确写出的企业性质；`src/lib/settings.js` 增加列配置和界面偏好默认值。
- 页面：`src/content/overlay.js` 核对面板；`src/dashboard/dashboard.html`、`dashboard.js`、`dashboard.css` 的列设置、概览折叠、企业性质标签与筛选；`src/workbench/workbench.html`、`workbench.js`、`workbench.css` 的头部压缩。
- 兼容性：旧记录与旧 JSON 备份缺少 `companyType`、列配置时使用默认值；不改状态词表、快捷键、消息协议和外部服务；不新增权限或第三方依赖。
- 验证与交付：扩展 `scripts/workbench-e2e.mjs`、`scripts/e2e-cdp.mjs` 的布局与交互断言，补充企业性质、列设置、概览折叠和侧栏模式用例；更新 README 截图与说明，并重新生成 `dist/job-tracker-extension-1.0.0.zip`。
