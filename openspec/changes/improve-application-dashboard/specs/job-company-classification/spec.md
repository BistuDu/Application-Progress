# Spec Delta

## Purpose

让用户在投递进度中记录并识别企业性质，在表格中快速区分央企、国企和私企，并能按性质筛选和导出。

## ADDED Requirements

### Requirement: 企业性质字段

系统 MUST 在每条岗位记录上保存企业性质，取值为 `央企`、`国企`、`私企`、`其他` 或空字符串（表示未标注）。框选核对面板、手动添加表单和详情抽屉 MUST 提供编辑入口；保存后 MUST 持久化，并在重新加载后保持。缺少该字段的旧记录 MUST 按未标注读取，不得因此报错或丢失其他字段。

#### Scenario: 保存手动选择的企业性质

- **WHEN** 用户在手动添加或详情抽屉中选择「国企」并保存
- **THEN** 记录的企业性质为「国企」，列表标签和重新加载后的详情都显示「国企」

#### Scenario: 读取旧记录

- **WHEN** 记录来自没有 `companyType` 字段的旧版本
- **THEN** 记录按未标注显示，其他字段、状态历史和截图保持可用

#### Scenario: 修改企业性质

- **WHEN** 用户把一条记录的企业性质从「未标注」改为「私企」并保存
- **THEN** 该记录立即显示「私企」标签，刷新页面后仍为「私企」

### Requirement: 企业性质自动建议

在框选核对和手动添加表单中，系统 SHALL 根据公司名词典和关键词规则给出企业性质建议；当识别文本明确出现企业性质（如“国有企业”“央企”）时 MUST 优先采用该明确信息。自动建议 MUST NOT 覆盖用户已经手动选择的值；用户修改公司名后，只有在其尚未手动选择企业性质时才允许更新建议。无法可靠判断时 MUST 保持未标注，不得默认标为私企。

#### Scenario: 公司名命中央企词典

- **WHEN** 识别或输入的公司名为「中国石化」且用户尚未选择企业性质
- **THEN** 表单建议「央企」，用户可以直接采用或改为其他类型

#### Scenario: 截图明确写出企业性质

- **WHEN** JD 截图中明确出现「国有企业」且公司名不在词典中
- **THEN** 表单采用「国企」，不依赖公司名猜测

#### Scenario: 未匹配公司名

- **WHEN** 公司名不在词典中，截图和正文也没有明确企业性质
- **THEN** 企业性质保持未标注，表单不显示臆测标签

#### Scenario: 用户选择后不被覆盖

- **WHEN** 用户已手动把企业性质改为「私企」，随后修改公司名称
- **THEN** 企业性质仍为「私企」，自动建议不得改写用户选择

### Requirement: 行内标签、可选列与性质筛选

投递表格默认 MUST 在公司名旁显示带文字的企业性质标签；用户 MAY 在列设置中打开独立的「企业性质」列，打开后行内标签 MUST 隐藏，避免同一信息重复显示。未标注的记录 MUST NOT 显示行内性质标签。筛选栏 MUST 提供「全部性质」「央企」「国企」「私企」「其他」「未标注」选项，选择后只显示匹配记录，并能与现有关键词、状态、来源、时间筛选组合使用。

#### Scenario: 显示企业性质标签

- **WHEN** 一条记录的企业性质为「央企」且企业性质列未打开
- **THEN** 表格在公司名后显示「央企」文字标签，标签颜色与其他类型可区分

#### Scenario: 打开企业性质列不重复

- **WHEN** 用户在企业性质列未显示时打开列设置并勾选「企业性质」
- **THEN** 表格新增企业性质列，公司名后的行内标签隐藏，屏幕上每行只出现一次类型信息

#### Scenario: 未标注不显示标签

- **WHEN** 一条记录的企业性质为空
- **THEN** 公司名后不显示行内性质标签，记录仍正常展示

#### Scenario: 按企业性质筛选

- **WHEN** 用户选择「私企」性质筛选
- **THEN** 列表只显示企业性质为「私企」的记录，计数同步更新

#### Scenario: 筛选未标注记录

- **WHEN** 用户选择「未标注」并同时输入关键词
- **THEN** 列表只显示企业性质为空且匹配关键词的记录

### Requirement: 企业性质导出

CSV 和 Markdown 导出 MUST 包含「企业性质」列；空值在导出中 MUST 显示为「未标注」。JSON 备份 MUST 原样保留企业性质字段，导入旧备份时缺少该字段 MUST 按未标注处理。

#### Scenario: CSV 导出

- **WHEN** 用户导出 CSV
- **THEN** 每行包含企业性质列，已标注记录显示类型，未标注记录显示「未标注」

#### Scenario: Markdown 导出

- **WHEN** 用户导出 Markdown
- **THEN** 投递表格包含企业性质列，岗位详情中可读到相同类型

#### Scenario: JSON 往返

- **WHEN** 用户导出 JSON 后重新导入
- **THEN** 已标注和未标注记录都保持原值，旧版 JSON 缺少字段时仍可成功导入
