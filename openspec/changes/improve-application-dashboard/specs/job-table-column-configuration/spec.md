# Spec Delta

## Purpose

让用户按自己的查看习惯选择投递表格显示哪些列、如何排序，并在窄侧栏自动使用精简列，保证列表始终可读。

## ADDED Requirements

### Requirement: 列设置入口与固定列

投递表格 MUST 在表头区域和筛选栏提供「列设置」入口。勾选框、公司/岗位和行操作 MUST 始终显示且不可隐藏；记录时间、地点、薪资、状态、投递日期、来源、下一步，以及企业性质、岗位类型、学历要求、经验要求、招聘人数、截止时间、投递方式、技能关键词、岗位摘要、备注、最后修改、状态变更、来源链接、页面标题、识别模型 MUST 可以分别显示或隐藏。企业性质和企业类型列打开时，公司名旁的重复行内信息 MUST 隐藏。首次使用且没有保存配置时，原有七列 MUST 默认显示，新增的扩展列 MUST 默认隐藏。

#### Scenario: 打开列设置

- **WHEN** 用户点击表头或筛选栏的列设置按钮
- **THEN** 出现可选列清单，当前显示状态、顺序和列宽与实际表格一致

#### Scenario: 隐藏可选列

- **WHEN** 用户取消勾选「薪资」和「来源」
- **THEN** 表格立即隐藏这两列，剩余列内容对齐且不出现空白占位

#### Scenario: 固定列不可隐藏

- **WHEN** 用户打开列设置
- **THEN** 勾选框、公司/岗位和行操作不出现在可取消的选项中

#### Scenario: 完整列目录

- **WHEN** 用户打开列设置并点击「全部显示」
- **THEN** 表格显示全部可选列，包括企业性质、岗位类型、学历、经验、人数、截止时间、投递方式、技能、摘要、备注、最后修改、状态变更、来源链接、页面标题和识别模型

#### Scenario: 企业性质列可选

- **WHEN** 用户勾选「企业性质」列
- **THEN** 表格新增企业性质列，公司名旁不再重复显示性质标签

#### Scenario: 新增列默认隐藏

- **WHEN** 用户从没有扩展列配置的版本升级后打开页面
- **THEN** 原有七列保持可见，扩展列默认隐藏，用户可按需打开

### Requirement: 列顺序

用户 MUST 能调整可选列的显示顺序。调整顺序 MUST 保持固定列位于表格两端，隐藏列 MUST 保留其相对顺序，重新显示时回到用户设定的位置。列设置 MUST 提供「恢复默认」，恢复后列内容和顺序回到默认状态。

#### Scenario: 拖拽排序

- **WHEN** 用户把「投递日期」拖到「状态」之前
- **THEN** 表格立即按新顺序显示，重新加载后顺序保持不变

#### Scenario: 隐藏列保留顺序

- **WHEN** 用户先调整「薪资」到「地点」之前，再隐藏「薪资」，之后重新显示
- **THEN** 「薪资」仍位于「地点」之前

#### Scenario: 恢复默认

- **WHEN** 用户点击「恢复默认」
- **THEN** 所有默认列重新显示，顺序恢复默认，固定列位置不变

### Requirement: 列宽可调整

用户 MUST 能拖动任意数据列（包括公司/岗位列）表头右边缘调整列宽，宽度 MUST 限制在可读范围内。双击调整手柄 MUST 恢复该列默认宽度；键盘聚焦手柄后 MUST 可用左右方向键调整，Home 键复位。列宽 MUST 持久化，并在页面刷新、浏览器重启、侧栏与全屏切换后保持。无效、过小或过大的列宽 MUST 被限制或回退默认值。

#### Scenario: 拖动调整列宽

- **WHEN** 用户把「薪资」列右边缘向右拖动 40px
- **THEN** 薪资列变宽约 40px，表格立即重新排版，其他列不受影响

#### Scenario: 双击恢复默认

- **WHEN** 用户双击「薪资」列的调整手柄
- **THEN** 薪资列恢复到默认宽度，并保存该默认值

#### Scenario: 键盘调整列宽

- **WHEN** 用户聚焦列宽手柄并按下左或右方向键
- **THEN** 列宽按固定步长缩小或放大，操作结果可被辅助技术感知

#### Scenario: 刷新后保持列宽

- **WHEN** 用户调整公司列宽度后刷新页面
- **THEN** 公司列仍保持用户设置的宽度

#### Scenario: 损坏列宽回退

- **WHEN** 保存的列宽为负数、非数字或超出允许范围
- **THEN** 该列回退到默认宽度或允许范围内的最近值，表格不出现负宽或空白

### Requirement: 列设置搜索与批量显示

列设置 MUST 提供按名称搜索列的能力，并 MUST 显示当前已显示列数与总列数。列设置 MUST 提供「全部显示」和「恢复默认」；「恢复默认」MUST 同时恢复默认列可见性、顺序和列宽。搜索不得修改列配置本身。

#### Scenario: 搜索列

- **WHEN** 用户在列设置搜索框输入「学历」
- **THEN** 清单只显示与「学历要求」匹配的列，其他列暂时隐藏

#### Scenario: 全部显示

- **WHEN** 用户点击「全部显示」
- **THEN** 所有可选列被勾选并在表格中显示，计数变为全部列数

#### Scenario: 恢复默认包含列宽

- **WHEN** 用户修改了列顺序、隐藏了列并调整了列宽后点击「恢复默认」
- **THEN** 列可见性、顺序和列宽全部回到初始状态，扩展列重新默认隐藏

### Requirement: 列配置持久化与回退

列配置和列宽 MUST 保存到扩展设置，并在页面刷新、浏览器重启、侧栏与全屏模式切换后保持一致。缺少配置、配置为空、包含未知列标识、顺序数据损坏或列宽非法时，系统 MUST 回退到默认列和默认列宽，不得出现空白表格或报错。

#### Scenario: 刷新后保持

- **WHEN** 用户隐藏「记录时间」并刷新投递进度页
- **THEN** 「记录时间」仍保持隐藏，其他列顺序不变

#### Scenario: 旧版本没有配置

- **WHEN** 用户从没有列配置的版本升级后打开页面
- **THEN** 表格使用完整默认列，不要求用户先配置

#### Scenario: 配置损坏

- **WHEN** 保存的配置包含无法识别的列标识
- **THEN** 未知标识被忽略，其余有效列正常显示，控制台不出现未处理异常

### Requirement: 侧栏精简模式

当投递进度页运行在侧栏或可用宽度小于 700 CSS 像素时，表格 MUST 自动使用精简列：保留勾选框、公司/岗位、状态（若用户已启用）和行操作，其余可选列隐藏。精简模式 MUST 隐藏列宽调整手柄并使用精简布局的列宽，MUST NOT 修改已保存的列配置和列宽；切回全屏后 MUST 恢复用户配置的列、顺序和列宽。

#### Scenario: 侧栏自动精简

- **WHEN** 用户在侧栏打开投递进度页，且已启用地点、薪资和来源
- **THEN** 侧栏只显示勾选框、公司/岗位、状态和操作，列内容不横向溢出

#### Scenario: 精简模式隐藏列宽手柄

- **WHEN** 用户在侧栏查看表格表头
- **THEN** 表头不显示列宽调整手柄，避免在窄屏误触调整

#### Scenario: 全屏恢复配置

- **WHEN** 用户从侧栏切到全屏
- **THEN** 地点、薪资和来源按用户之前的配置重新显示

#### Scenario: 精简不修改配置

- **WHEN** 用户在侧栏查看后回到设置页或重新打开全屏
- **THEN** 已保存的列配置与侧栏精简前完全一致

### Requirement: 列设置可访问性

列设置浮层 MUST 可通过键盘打开和操作，包含可读的复选标签和排序控件；按 Escape 或点击浮层外部 MUST 关闭浮层，关闭后焦点 MUST 返回触发按钮。拖拽排序 MUST 提供键盘可用的替代操作。

#### Scenario: 键盘关闭

- **WHEN** 列设置浮层打开时用户按 Escape
- **THEN** 浮层关闭，焦点回到列设置按钮

#### Scenario: 键盘调整顺序

- **WHEN** 用户聚焦某一列并使用键盘上移或下移
- **THEN** 该列顺序改变，表格同步更新，操作结果可被辅助技术读出
